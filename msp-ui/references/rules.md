# 設計規則全文

## 1. 顏色各司其職

| 顏色 | 代號 | 用在哪裡 | 不能用在哪裡 |
| --- | --- | --- | --- |
| 品牌紅 | `--red` | 目前所在的導覽項目、分頁底線、待處理數量、今天的日期標記、圖表門檻線與需要注意的序列 | 按鈕、大面積底色、錯誤訊息 |
| 品牌藍 | `--blue`、`--blue-solid`、`--blue-strong` | 所有可操作的東西：主要按鈕、連結、焦點外框、已選取、開關、進度 | 純裝飾 |
| 品牌深藍 | `--navy`、`--navy-2` | 只用在導覽列與頁首。兩種主題下都是深藍底 | 內容區的卡片或區塊 |
| 中性色 | `--paper`、`--surface`、`--sunken`、`--line`、`--ink` 系列 | 內容區的底色、容器、邊線、文字 | |
| 語意色 | `--ok`、`--warn`、`--bad` 與對應的 `-tint` | 成功、警告、錯誤 | 與品牌色互相借用 |

- 錯誤與刪除用 `--bad`（比品牌紅暗），並且一定同時有圖示和文字。
- 頁面最上方固定一條紅藍雙色線（`.brand-bar`）。
- Logo 放在 `.logo-chip`（白底小方塊）內的 `.logo-slot`，確保在深藍底上清楚。

## 2. 主題

1. 只提供淺色與深色，不新增其他主題。
2. 顏色只能透過代號取用，元件內不寫死色碼。
3. 每個元件都要在兩種主題下各檢查一次。
4. 深色不是把淺色反相：底色用帶藍調的深灰，品牌紅藍調亮以維持對比。
5. 預設跟隨系統設定；使用者切換後記住選擇（`MSP.setTheme`，存在 localStorage）。
6. 導覽列與頁首在兩種主題下都是深藍底。

切換方式是在 `<html>` 上設定 `data-theme="light"` 或 `data-theme="dark"`。

## 3. 字體

- 內文 14px，行高 1.6。字級只用 12、13、14、16、20、26、34。
- 英數：IBM Plex Sans（隨附）。等寬：IBM Plex Mono（隨附）。
- 中文：系統字體，順序為微軟正黑體、蘋方、Noto Sans TC。不隨附中文字體。
- 暫存器位址、數值、版本號、檔名、指令一律用等寬字（`.mono`）。
- 會對齊成欄的數字加 `.num`。

## 4. 禁止事項

- 不使用 emoji。圖示一律用圖示集的 SVG。
- 不使用瀏覽器原生外觀的控制項：
  - 不用 `<select>`，改用 `.select`
  - 不用 `input type="date"`，改用 `.datepicker`
  - 不用 `input type="range"`，改用 `.slider`
  - 不直接顯示 `input type="file"`，改用 `.dropzone`
  - 不用 `alert()`、`confirm()`、`prompt()`，改用 `.dialog` 與 `MSP.toast`
  - 不用 `title` 屬性當提示，改用 `data-tip`
  - 勾選、單選、開關用 `.check`、`.radio`、`.switch`（內部保留隱藏的 input 以支援鍵盤與表單）
- 不載入任何外部網址的樣式、腳本、字體、圖片。
- 陰影只給浮層（選單、對話框、通知）。
- 圓角依角色：控制項 6px、容器 10px、對話框 12px、狀態標籤全圓。

## 5. 文字

- 按鈕寫出按下去會發生的事（「儲存設定」而不是「確定」）。同一個動作在流程中名稱一致。
- 每個畫面只有一個主要按鈕（`.btn-primary`）。
- 錯誤訊息說明哪裡不對以及怎麼修正。
- 空白畫面要提供開始的動作。
- 狀態一定同時有顏色、圓點和文字。

## 6. 圖表

- 折線與長條一律透過 `MSP.chart` 建立，不直接呼叫 Chart.js。
- 序列顏色依序取 `--chart-1` 到 `--chart-5`，第一個是品牌藍。
- 紅色不當一般序列色，只用在門檻線（`threshold`）和標記為 `highlight` 的序列。
- 每張圖最多五個序列，超過就拆圖或改用表格。
- 每個 `<canvas>` 要有 `role="img"` 和說明內容的 `aria-label`。

## 7. 已知限制

- 日期選擇器只支援單一日期。日期區間請放兩個日期選擇器（起、迄）。
- 頁面載入後才用程式加入的元件（`.select`、`.datepicker`、`.tabs` 等）不會自動綁定行為。
  需要動態顯示的元件請一開始就寫在 HTML 裡，用 `hidden` 屬性控制顯示。
- 下拉選單放在對話框內時，選項較多可能需要在對話框內捲動。
- 字體檔只含拉丁字元，中文使用系統字體。
