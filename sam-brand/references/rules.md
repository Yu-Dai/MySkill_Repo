# 規則全文

分成兩部分：第一部分是所有帶 SAM 品牌的頁面都要遵守的鎖定項目，`scripts/check.js` 會檢查；
第二部分是使用隨附元件包時才適用的慣例。兩者以外的事（版面、字級、圓角、陰影、動態、密度）由設計者決定。

## 一、鎖定項目

### 1. 色票

| 顏色 | 代號 | 用在哪裡 | 不能用在哪裡 |
| --- | --- | --- | --- |
| 品牌紅 | `--red` | 點綴與標示：目前位置、待處理數量、需要注意的東西 | 錯誤訊息、大面積底色 |
| 品牌藍 | `--blue`、`--blue-solid`、`--blue-strong` | 所有可操作的東西：主要按鈕、連結、焦點外框、已選取、開關、進度 | |
| 品牌深藍 | `--navy`、`--navy-2` | 承載品牌的面：導覽、頁首、封面。兩種主題下都是深藍底 | |
| 中性色 | `--paper`、`--surface`、`--sunken`、`--line`、`--ink` 系列 | 底色、容器、邊線、文字 | |
| 語意色 | `--ok`、`--warn`、`--bad` 與對應的 `-tint` | 成功、警告、錯誤 | 與品牌色互相借用 |

- 顏色只能透過代號取用，不寫色碼、`rgb()`、顏色名稱。
- 需要其他深淺時用 `color-mix()` 從代號混出來。陰影同理：用 `--shadow`，或 `color-mix(in srgb, var(--ink) 16%, transparent)`。
- 不重新定義代號的值。
- 錯誤與刪除用 `--bad`（比品牌紅暗），並且同時有圖示或文字。

### 2. 淺色與深色

- 兩種主題都要能用。顏色都用代號就會自動成立。
- 預設跟隨系統設定；要讓使用者切換時，在 `<html>` 上設定 `data-theme="light"` 或 `data-theme="dark"`。
- 深色不是把淺色反相：代號已經處理好，不要自己再調。

### 3. Logo

- 每個頁面都要出現 `assets/logo.png`。嵌在其他頁面內的片段可以用 `check.js --no-logo` 略過。
- 位置與大小自由。放在深色或有顏色的底上時墊白底。
- 不變形、不改色、不用文字代替。

### 4. 不連外

- 不載入任何外部網址的樣式、腳本、字體、圖片。
- 要用隨附以外的字體或函式庫時，把檔案連同授權放在頁面旁，用相對路徑載入。

### 5. 不用原生控制項

- 不用 `<select>`、`input type="date"`、`input type="range"`、`input type="color"`。
- `input type="checkbox"`、`radio`、`file` 要重畫外觀（保留 input 本身，加上 class 後重畫，或包進元件包的對應元件）。
- 不用 `alert()`、`confirm()`、`prompt()`。
- 不用 `title` 屬性當提示。
- 不用 emoji 和符號字元當圖示，用 SVG。

### 6. 無障礙底線

- 每個 `<canvas>` 要有 `role="img"` 和說明內容的 `aria-label`。
- 鍵盤焦點要看得見。
- 狀態同時有顏色與文字。

## 二、元件包慣例（用了 sam-ui.css 與 sam-ui.js 才適用）

### 腳本與圖示

- `sam-ui.js` 放在 `</body>` 前、頁面內容之後；頁面自己的程式放在它後面。
- 用到圖表時順序是 `chart.umd.js`、`sam-ui.js`、`sam-chart.js`。
- 頁面開頭要貼上 `assets/icons.html` 的全部圖示。

### 對應的替代元件

| 原生 | 元件包 |
| --- | --- |
| `<select>` | `.select` |
| `input type="date"` | `.datepicker` |
| `input type="range"` | `.slider` |
| `input type="file"` | `.dropzone` |
| 勾選、單選、開關 | `.check`、`.radio`、`.switch` |
| `alert()`、`confirm()` | `SAM.toast`、`.dialog` |
| `title` | `data-tip` |

### 圖表

- 載入 `sam-chart.js` 的頁面用 `SAM.chart` 建立折線與長條，不直接呼叫 Chart.js。
- 序列顏色依序取 `--chart-1` 到 `--chart-5`；紅色只用在門檻線和標記為 `highlight` 的序列。

### 建議（不檢查）

- 按鈕寫出按下去會發生的事（「儲存設定」而不是「確定」），同一個動作在流程中名稱一致。
- 一個畫面只突顯一個最重要的動作。
- 錯誤訊息說明哪裡不對以及怎麼修正；空白畫面提供開始的動作。
- 暫存器位址、數值、版本號、檔名、指令用等寬字。

### 已知限制

- 日期選擇器只支援單一日期。日期區間請放兩個日期選擇器（起、迄）。
- 頁面載入後才用程式加入的元件（`.select`、`.datepicker`、`.tabs` 等）不會自動綁定行為。
  需要動態顯示的元件請一開始就寫在 HTML 裡，用 `hidden` 屬性控制顯示。
- 下拉選單放在對話框內時，選項較多可能需要在對話框內捲動。
- 字體檔只含拉丁字元，中文使用系統字體。
