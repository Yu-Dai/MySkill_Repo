# ToMarkdown

把文件轉成 Markdown，給 LLM 建知識庫時閱讀。

## 三條必須遵守的規則

1. **轉檔前一定要先問使用者要用「快速」還是「精準」，等他回答後才執行。** 不可以自己決定，也不可以因為「預設是快速」就直接用快速。唯一的例外：使用者在這次的要求裡已經明確寫了要用哪一種。
2. **不要自己寫程式解析檔案，一律用這裡的腳本轉。**
3. **不要打開 `config.json`。** 裡面有金鑰。要知道設定狀態，看腳本印出的訊息。

以下 `SKILL_DIR` 代表這個 SKILL.md 所在的資料夾，執行指令時換成實際路徑。

## 流程

### 第 1 步：問使用者要用哪種方式

先不加 `--mode` 執行一次。這次不會轉檔，腳本會印出要問使用者的問題，以及精準方式目前能不能用：

```
"SKILL_DIR\to_markdown.cmd" 檔案或資料夾 -o 輸出資料夾
```

把腳本印出的問題**原樣**問使用者，然後**停下來等使用者回答**。

- 腳本說精準「目前不可用」時，把原因照實告訴使用者。他仍然要選精準的話，請他先把設定補好，不要執行。
- 一次要轉多個檔案時只問一次，整批用同一種方式。

兩種方式的差別：

| 方式 | 做什麼 | 適合 |
|------|--------|------|
| 快速 | 只用腳本抽文字、表格、圖片，幾秒內完成 | 以文字與表格為主：register table、protocol、規格書 |
| 精準 | 另外請看圖模型描述每張圖、補上腳本抽不到的表格，圖多時要幾分鐘 | 以圖為主：含方塊圖或時序圖的 datasheet、含流程圖的簡報、掃描的 PDF |

### 第 2 步：照使用者的回答執行

使用者選快速：

```
"SKILL_DIR\to_markdown.cmd" 檔案或資料夾 -o 輸出資料夾 --mode fast
```

使用者選精準：

```
"SKILL_DIR\to_markdown.cmd" 檔案或資料夾 -o 輸出資料夾 --mode precise
```

- 可以一次給多個檔案或資料夾，資料夾會往下找所有支援的檔案。
- 輸出是 `輸出資料夾/檔名.md`；有圖片時另有 `輸出資料夾/檔名_assets/`。兩者必須放在一起。
- 不是 Windows 時，把 `"SKILL_DIR\to_markdown.cmd"` 換成 `python "SKILL_DIR/scripts/to_markdown.py"`。

### 第 3 步：把腳本印出的訊息回報給使用者

每個檔案會印出以下幾種訊息，**全部都要告訴使用者**：

| 訊息 | 意思 | 你要做的事 |
|------|------|------------|
| `[完成]` 加 `[檢查] 文字覆蓋通過` | 轉好了，內容沒有遺漏 | 告訴使用者輸出位置 |
| `[檢查] 有 N 段來源文字沒有出現在輸出` | 有內容遺失 | **不可當作成功**，把缺漏的文字列給使用者 |
| `[警告]` | 例如公式沒有計算結果、截圖沒產生 | 照原文轉述 |
| `[需要另存]` | 這是舊格式（xls、ppt、doc），不能直接轉 | 照訊息告訴使用者：自己用 Office 開啟，另存成新格式，再拿來轉 |
| `[失敗]` | 這個檔案轉不了 | 把原因照原文告訴使用者 |
| `[略過]` | 不支援的格式 | 告訴使用者 |

### 第 4 步：抽查輸出

打開轉出的 Markdown，確認：

- 十六進位值、位元範圍、前導零原樣保留（`0x1F`、`7:4`、`0007`）。
- 表頭合理。多列表頭會被壓平成 `上層 / 下層`。
- pptx 的「連接關係」標有「推測」的項目是依線條位置猜的，要對照截圖。
- pdf 標有「請看整頁截圖」的頁面，腳本抽出的內容可能不完整。

發現問題時告訴使用者是哪個位置，不要手動改 Markdown 來掩蓋。

## 支援格式

| 格式 | 狀態 |
|------|------|
| xlsx、xlsm、csv、docx、docm、pptx、pptm | 可用，不需要安裝任何套件 |
| pdf | 可用，需要 PDF 套件；沒有時腳本會說明缺什麼 |
| xls、ppt、doc 等舊格式 | **不支援。** 請使用者自己用 Excel、PowerPoint、Word 開啟，另存成 xlsx、pptx、docx 後再轉 |

pptx 含圖解的投影片會呼叫本機的 PowerPoint 轉成截圖（只有 Windows 可以）。失敗時只會有警告，文字內容照常輸出。

## 精準方式的輸出

模型寫的內容都在引言區塊內，以 `[AI 描述，請對照原圖]` 或 `[AI 轉寫，請對照原圖]` 開頭。
**引用這些內容時要說明它是模型產生的**，數值與位元欄位以原圖為準。

## 設定

設定檔是 `SKILL_DIR/config.json`，範本是 `config.example.json`。由使用者自己填，你不要讀也不要改。

要檢查環境與設定是否就緒，執行：

```
"SKILL_DIR\to_markdown.cmd" --check
```
