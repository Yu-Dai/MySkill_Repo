# ToMarkdown 輸出規格

這份規格定義「轉完應該長什麼樣」，也是驗收標準。實作要對齊這裡，不是反過來。

目的：轉出的 Markdown 給 LLM 建知識庫用。判斷取捨時以「LLM 檢索與閱讀」為準，不以人眼排版為準。

## 狀態

| 格式 | 狀態 |
|------|------|
| xlsx | 已實作（圖表資料序列尚未做） |
| csv | 已實作 |
| docx | 已實作 |
| pptx | 已實作（投影片截圖只能在 Windows 執行，尚未實機驗證；圖表資料尚未做） |
| pdf | 未實作 |
| 精準模式（看圖） | 未實作 |

## 共通規則

### 輸出位置

```
輸出資料夾/
  檔名.md
  檔名_assets/        只有來源含圖片或截圖時才建立
    img-001.png
    page-003.png
    slide-05.png
```

- 圖片一律存成旁檔，Markdown 內只放相對連結。不內嵌 Base64：它會吃掉大量 token，也會破壞知識庫的切塊。
- 相同內容的圖片只存一份（以內容雜湊判斷）。

### 檔頭

每個檔案以 YAML front matter 開頭：

```markdown
---
source: "register_map.xlsx"
type: xlsx
converter: "to-markdown 0.1.0"
mode: fast
---
```

各格式可再加自己的欄位（例如 xlsx 的 `sheets`）。不寫轉檔時間，這樣同一份來源重轉的結果完全相同，方便比對差異。

### 分段與來源定位

- 分段一律用 Markdown 標題，因為切塊工具依標題切。
- 每段都帶來源定位：xlsx 是 sheet 名稱與儲存格範圍，pdf 是頁碼，pptx 是投影片編號。

### AI 產生的內容

精準模式下由模型寫出的文字，一律用引言區塊並加固定標記，後面保留原圖連結：

```markdown
> [AI 描述，請對照原圖] 這張圖是開機流程……
> [AI 轉寫，請對照原圖]
```

模型轉寫十六進位與位元欄位可能出錯，所以這類內容不可與腳本抽取的內容混在一起。

### 模式

| | 快速 fast | 精準 precise |
|---|---|---|
| 文字、表格 | 腳本抽取 | 同左 |
| 圖片 | 存檔＋連結 | 存檔＋連結＋AI 描述 |
| 腳本處理不了的頁面 | 截圖連結＋標記 | 截圖連結＋AI 轉寫 |
| 需要 API | 否 | 是 |

## xlsx

```markdown
---
source: "register_map.xlsx"
type: xlsx
converter: "to-markdown 0.1.0"
mode: fast
sheets: ["Register", "Protocol"]
hidden_sheets_skipped: ["tmp"]
---

# register_map.xlsx

## Sheet: Register

### Table 1 (A1:F12)

**Touch IC Register Map**

| Addr | Name | Bit | Field / Name | Field / Default |
|------|------|-----|--------------|-----------------|
| 0x1F | CTRL | 7:4 | MODE | 0x0 |
| 0x1F | CTRL | 3:0 | GAIN | 0x3 |

![圖片（錨定 H3）](register_map_assets/img-001.png)

**儲存格註解**

- C5：保留位元，寫入時必須為 0
```

規則：

1. **合併儲存格：** 拆開後把左上角的值填滿範圍內每一格。這樣每一列都自帶位址與名稱，檢索切到任何一列都看得懂。
2. **多列表頭：** 壓平成單列，上下層用 ` / ` 連接（例如 `Field / Default`）。判斷依據是表頭列的合併儲存格。
3. **一個 sheet 多張表：** 以整列空白、整欄空白切開，各自輸出成一張表，標題帶儲存格範圍。
4. **表格標題列：** 表格上方橫跨整張表的單一文字，輸出成表格前的粗體字，不放進表格。
5. **只有一欄的區塊：** 視為說明文字，逐列輸出成段落，不做成表格。
6. **數值取顯示值：** 套用儲存格的數字格式（補零、小數位數、百分比、千分位、日期、前後綴文字），不輸出底層數值。公式取 Excel 存下的計算結果。
7. **日期：** 一律輸出成 `YYYY-MM-DD`、`YYYY-MM-DD HH:MM`。
8. **隱藏的 sheet：** 預設略過，名稱列在檔頭的 `hidden_sheets_skipped`。隱藏的列與欄照常輸出。
9. **儲存格註解：** 列在該 sheet 最後。
10. **圖片：** 存成旁檔，連結放在錨定位置所屬的表格之後，並標註錨定的儲存格。
11. **儲存格內換行：** 轉成 `<br>`。`|` 轉成 `\|`。

已知限制：

- 圖表目前不輸出（規劃輸出標題與資料序列）。
- 表格中間若有整列空白，會被切成兩張表，第二張表沒有表頭。
- 公式若沒有儲存計算結果（檔案由程式產生、從未用 Excel 開過），該格為空，轉檔時會列出警告。
- 少見的數字格式（分數、科學記號、條件格式）以一般數值輸出。

## csv

```markdown
---
source: "log.csv"
type: csv
converter: "to-markdown 0.1.0"
mode: fast
encoding: "cp950"
delimiter: ","
---

# log.csv

### Table 1 (3 欄 × 120 列)

| time | addr | value |
|------|------|-------|
```

規則：

1. **編碼：** 依序嘗試 BOM、UTF-8、Big5（cp950）。偵測結果寫進檔頭。
2. **分隔符號：** 自動判斷逗號、分號、Tab、`|`。
3. **第一列當表頭。** 欄數不齊的列補空白。

## docx

```markdown
# driver_guide.docx

**Demo Touch Driver 使用說明**

## 1 概述

本文件說明初始化流程。

1. 上電並等待 10 ms
1. 讀取 CHIP_ID

| Addr | Name | Field / Bit | Field / Default |
|---|---|---|---|
| 0x1F | CTRL | 7:4 | 0x0 |

![圖片](driver_guide_assets/img-001.png)
```

規則：

1. **標題：** 檔名佔用第一層 `#`，所以 Word 的「標題 1」輸出成 `##`，依此類推。「Title」樣式輸出成粗體字。
2. **清單：** 項目符號輸出成 `-`，編號清單一律輸出成 `1.`，階層用縮排表示。
3. **表格：** 合併儲存格、多列表頭的處理同 xlsx。只有一欄的表格視為排版用外框，直接輸出內容。
4. **圖片：** 存成旁檔，連結放在原本的位置。有替代文字時當作圖片說明。
5. **文字方塊：** 內容輸出在所在段落之前。
6. **超連結：** 輸出成 `[文字](網址)`。
7. **追蹤修訂：** 取接受後的結果（新增的保留，刪除的略過）。
8. **略過：** 目錄、頁首、頁尾。

已知限制：

- 自動編號的實際數字不會輸出。標題若靠 Word 自動編號（1.1、1.2），轉出後只有標題文字。
- 註腳、尾註、註解不輸出。
- 粗體、斜體等字元格式不保留。
- 方程式不輸出。

## pptx

```markdown
## Slide 2: 開機流程

![slide-02](deck_assets/slide-02.png)

**圖中文字：** Power On、Load FW、Check CRC、Fail、Normal Mode

**連接關係：** Power On → Load FW；Load FW → Check CRC；Check CRC → Fail（推測）

**講者備註：** ……
```

規則：

1. **標題：** 每張投影片一個 `## Slide N: 標題`。隱藏的投影片照常輸出並標註「（隱藏）」。
2. **內文版面配置區：** 輸出成清單，階層用縮排表示。
3. **圖解頁的判定：** 投影片有任何線條，或有 4 個以上的自由文字圖案，就視為圖解頁。
4. **圖解頁：** 圖案文字依位置由上到下、由左到右列在「圖中文字」；連接線列在「連接關係」。
5. **連接線：** 有黏在圖案上的直接採用檔案內的紀錄。沒黏上的，看線段端點是否落在某個圖案附近（投影片寬度的 2.5% 內），並標「推測」。兩端有任一端找不到對象就不輸出，只統計數量。
6. **箭頭：** 單向箭頭 `→`、雙向 `↔`、沒有箭頭 `—`。
7. **投影片截圖：** 只有圖解頁會轉圖。透過 PowerShell 呼叫本機的 PowerPoint 匯出，只能在 Windows 執行；其他環境會警告並略過。
8. **表格、圖片、SmartArt 文字、講者備註：** 依序輸出在該投影片下。

已知限制：

- 以動畫疊層的投影片，截圖是全部疊在一起的最終狀態。
- 箭頭樣式若來自佈景主題而非線條本身，會被當成沒有箭頭。
- 旋轉過的線條，端點位置以未旋轉計算，推測可能不準。
- 圖表只標示存在，資料尚未輸出。
- 版面配置與母片上的文字不輸出。

## pdf（未實作，預定格式）

```markdown
## Page 3

（腳本抽出的文字與表格）

![圖 3-1](spec_assets/p003-img-01.png)

> [此頁含腳本無法可靠抽取的內容，請看截圖](spec_assets/page-003.png)
```

- 有文字層的頁面：腳本抽文字、有框線的表格、內嵌圖片。
- 問題頁（掃描、無框線表格、複雜多欄、公式）：附整頁截圖連結。快速模式只標記，精準模式由模型轉寫。
- 相依：pdfplumber、pypdfium2（寬鬆授權）。不使用 PyMuPDF（AGPL）。

## 驗收檢查

每次轉檔自動做：

1. **文字覆蓋：** 來源每個非空儲存格的顯示值，都必須出現在輸出裡。缺漏數量列在轉檔結果。
2. **表格形狀：** 每張表輸出的列數、欄數與偵測到的範圍一致。

需要人工或 LLM 做：

3. **十六進位與位元欄位原樣保留**（`0x1F`、`7:4`、前導零）。
4. **樣本問答：** 對轉出的 Markdown 問原檔能回答的問題，看答得出來與否。
